# Developer tools: tokenizer comparison and portable GitHub demos

Compare the same text with eight tokenizers, then inspect token IDs and estimate input cost using your own rates. The interface supports English, Chinese, Japanese and Korean, with built-in Japanese and Korean samples.

Added GLM-5, Kimi K2.5 and Anthropic's official **legacy** tokenizer alongside Qwen3, DeepSeek V3, Mistral and two GPT encodings. The legacy Claude tokenizer is not accurate for current Claude 3+ models. Plain-text counts are not complete API billable usage.

The repository now includes an English/Chinese tool directory, portable model and image arenas, a decision playground, pricing resources, and a standalone tokenizer source package. Browser-based demos require no local installation. Live inference requires your own key and may incur API charges.

- [Compare tokens](https://xujfcn.github.io/crazyrouter-tools/tokenizer-comparison/)

- [Read API documentation](https://docs.crazyrouter.com/?utm_source=github&utm_medium=github_release&utm_campaign=developer_tools_launch&utm_content=docs)

Validation: complete token IDs are compared with native reference implementations on 24 inputs per tokenizer. Claude legacy is also compared against the official Anthropic package. Browser checks cover language switching, preserved results, mobile layouts, error recovery and safe text rendering. This finite coverage is not a guarantee for every Unicode input.
