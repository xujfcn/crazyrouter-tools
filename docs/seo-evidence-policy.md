# SEO evidence policy

Reviewed 2026-10-11. This is an editorial review date, not an official model verification date.

The root sitemap lists formal crazyrouter.com/tools canonical URLs. The github/sitemap.xml file remains dedicated to the separately hosted GitHub promotion pages. Do not overwrite the root sitemap with that promotion feed.

Legacy comparison scores, capabilities and prices without per-model sources are withheld. Radar rows expose source references and an unverified state; historical scores in data.js are not shown as current rankings. Before publishing verified numbers, retain exact model variant, measurement definition, source URL, collection date and actual verification date. Do not convert the build timestamp into a source date.

All four radar languages have complete static guidance and model rows. Filtering works with a shared script; missing data cannot erase the static content. Existing GitHub promotion URLs retain their deliberate GitHub canonical rather than duplicating them into the formal sitemap.
