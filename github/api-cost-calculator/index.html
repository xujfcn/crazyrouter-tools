API Token 费用计算公式

总费用 = 请求次数 ×（平均输入 Token × 输入单价 + 平均输出 Token × 输出单价）÷ 1,000,000

这个公式适用于输入、输出单价均为“美元 / 百万 Token”的普通文本请求。若每次请求长度差异大，应分别计算后求和，或用真实日志计算平均值；重试产生的有效计费用量也要纳入预算。

算一个例子：1,000 次请求需要多少钱？

以下仅是公式演示，不是任何模型的报价：假设输入单价为 2 美元 / 百万 Token，输出单价为 8 美元 / 百万 Token，每次输入 500 Token、输出 100 Token，共调用 1,000 次。

  • 输入：1,000 × 500 ÷ 1,000,000 × 2 = 1 美元。
  • 输出：1,000 × 100 ÷ 1,000,000 × 8 = 0.8 美元。
  • 总计：1.8 美元，不包含其他费用。

为什么聊天越长，API 消费越高？

很多聊天应用每轮都会重新提交部分或全部历史消息。用户这一轮只输入一句话，API 的输入却可能包含此前数轮对话、系统提示和工具说明。应按实际发送的 messages 或 input 计算，而不是只看最后一条消息。

缓存、推理 Token 和长上下文怎样影响费用？

  • 缓存：缓存读取可能使用较低单价，缓存写入也可能单独收费。命中规则与有效期因提供商而异。
  • 推理：某些模型的推理 Token 计入输出预算或另有用量字段，不能只统计屏幕上可见的回答。
  • 上下文档位：部分价格会随输入长度、批处理模式或服务层级改变。
  • 图片、音频、视频和工具：可能按图片、时长、调用次数或其他单位计费，不适合套用纯文本公式。

ChatGPT 订阅包含 API 额度吗？

ChatGPT 产品订阅和 API 平台通常是不同的计费体系，不能把网页会员费理解成通用 API 余额。同样，其他聊天产品的会员权益也不应直接当作开发者 API 额度；以具体产品的官方说明为准。

怎样比较哪个 API 更省钱？

  1. 用真实的中文、英文或代码输入估算目标模型 Token 数。
  2. 选择相同请求量和输出长度，再比较各模型单价。
  3. 观察任务成功率、重试率和延迟：便宜但频繁失败的调用不一定有更低的任务成本。
  4. 上线后对照 API usage 与账单，把估算修正为实际平均成本。

API 费用计算：常见问题

1M Token 是多少？

价格表里通常指一百万 Token。把每千 Token 单价换成每百万 Token 单价时，需要乘以 1,000。

输出 Token 为什么要单独计算？

许多模型对生成内容采用不同于输入的单价。只算输入会低估总费用，尤其是长回答或推理任务。

计算器中的价格是实时的吗？

不是。页面明确展示价格快照日期，并提供来源链接。请在购买或做预算决策前核对当前价格。

API 调用失败也会收费吗？

是否产生费用取决于请求是否已执行、提供商规则及返回的用量。网络超时不一定代表模型没有运行，应结合用量记录核对。
