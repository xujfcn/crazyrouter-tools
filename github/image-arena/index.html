What this shows


Same prompt, same size, one shot per model — no cherry-picking, no reruns beyond the single retry recorded in gallery.json for 429/5xx errors. It is a quick visual sense of style, text rendering and prompt adherence across providers, not a benchmark or a quality ranking. All gallery requests were sent with response_format: "b64_json" (or output_format: "png" for gpt-image-*, which reject response_format); models that only return URLs were downloaded server-side. Prices come from Crazyrouter's pricing page at build time and may change.
