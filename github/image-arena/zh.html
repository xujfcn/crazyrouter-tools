每次运行都会用你自己的余额，对每个模型各发送一次真实的付费请求，不会自动重试。部分模型会以 HTTP 400 拒绝某些尺寸——那是上游限制而不是模型失败。只返回图片地址而非图片字节的模型会直接按该地址显示，地址通常过一段时间就会失效。

这里展示的是什么


同一提示词、同一尺寸、每个模型只生成一次——不挑图，除了 gallery.json 里记录的针对 429/5xx 的一次重试外不再重跑。它能让你快速直观地感受各家模型的风格、文字渲染和对提示词的遵循程度，但不是基准测试，也不是质量排名。画廊请求均带 response_format: "b64_json"（gpt-image-* 拒绝该参数，改用 output_format: "png"）；只返回地址的模型由服务端下载。价格来自构建时的 Crazyrouter 价格页，可能变动。
