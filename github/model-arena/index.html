What the probes measure


The candy verdict only checks whether the answer contains the standalone number 21; it is not a semantic grade. The pelican verdict passes when the SVG parses, contains no scripts or external references, declares an animation, and shows the nonce in a <text> element. Neither probe proves model identity or overall capability. Prompts are copied verbatim from manxue-ai so results are comparable with manxue.ai.
