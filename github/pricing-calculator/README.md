# API cost calculator

[Open calculator](https://xujfcn.github.io/crazyrouter-tools/github/pricing-calculator/)

Use expected request count, input tokens, output tokens and model prices to estimate costs. The calculator uses a public catalogue snapshot dated 2026-09-29; the accompanying provider-comparison dataset has its own source dates. These are planning estimates, not live quotes.

Input cost = requests × input tokens × input price / 1,000,000. Output cost uses the same formula. Cache, images and other charges need separate treatment.
