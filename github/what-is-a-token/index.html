Token 是什么？中文怎么算、1K/1M Token 与分词器对比

Token 是大语言模型处理文本时使用的基本单位。它可能是一个词、词的一部分、标点，或字符编码的一部分；它不等于一个汉字，也不等于一个英文单词。同一段文本交给不同模型的分词器，得到的 Token 数可能不同。

一个 Token 等于几个汉字？为什么没有固定答案？

分词器根据词表与编码规则把文本切成片段。常见词、少见字、中英文混排、空格和 emoji，都可能影响切分结果。把“一个 Token 等于几个汉字”当成固定公式，容易低估中文、代码或多语内容的长度。

想知道一段中文具体用了多少 Token，最可靠的操作是选择目标模型对应的分词器，把原文直接输入工具。复制文本时也要保留换行与空格，因为它们会影响切分。

1K Token、1M Token 和上下文长度分别是什么？

价格表中的 1K 通常表示 1,000 个 Token，1M 表示 1,000,000 个 Token。上下文窗口是一次请求可处理内容的容量限制，需要核对具体模型是否把输入、输出及推理部分共同计入；它不是免费额度，也不等于一次回答一定能输出的长度。

输入 Token、输出 Token、缓存 Token 有什么区别？

  • 输入 Token：提交给模型的内容，可能包括系统指令、用户消息、历史对话及工具定义。
  • 输出 Token：模型生成的内容；部分模型还会报告或计费不可见的推理 Token。
  • 缓存 Token：提供商识别并复用的输入片段，缓存读取与写入的计价规则需要分别核对。

聊天越久，随请求重新发送的历史越多，输入费用可能越高。网页上的“字符数”可以帮助观察文本规模，但不能替代 Token 数。

如何用分词结果估算 API 费用？

  1. 选择目标模型或匹配的编码方案，粘贴完整文本。
  2. 比较 Token 数和拆分片段，检查中文、日文、韩文或代码的差异。
  3. 输入模型每百万输入 Token 的单价，得到这段纯文本的输入费用估算。
  4. 把输出预算、消息封装、工具和图片等额外开销加入 API 费用计算。

本地工具不上传输入文本。纯文本计数与 API 实际 usage 可能不同，最终以提供商报告的用量和计费规则为准。

Token 是什么：常见问题

Token 就是 API Key 吗？

不是。在大模型计数语境下，Token 指文本处理单位；访问令牌或 API Key 是身份凭证，不应该粘贴到分词器或公开测试样例里。

为什么同一句话在不同模型下 Token 数不同？

不同模型可能使用不同的词表、规范化规则和编码方案。差异反映切分方式，不能单独用来判断模型好坏或总费用。

中文、日文、韩文可以一起计算吗？

可以。工具接受混合语言输入，并提供中、英、日、韩示例。请使用目标模型对应的分词器，而不是按字符数直接换算。

为什么本地 Token 数小于 API 返回的输入用量？

API 请求还可能包含聊天模板、系统提示、历史消息、工具定义和多模态内容。这些内容不一定出现在你粘贴的纯文本中。
