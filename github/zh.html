Token 是什么？在线计算与分词器对比

Token 是大语言模型处理文本时使用的基本单位。它可能是一个词、词的一部分、标点，或字符编码的一部分；它不等于一个汉字，也不等于一个英文单词。同一段文本交给不同模型的分词器，得到的 Token 数可能不同。

AI 工具常见问题

这些工具需要 API Key 吗？

Token 计算和 API 费用计算不需要 API Key。模型与图片样例可以直接浏览；实时模型测试、生图和 JEV 请求需要自己的密钥，可能产生费用。

GPT 满血 / 残血测试能证明模型真假吗？

不能。它帮助对比特定任务表现、排查配置与接口异常。单次答题、模型自述或自动规则通过，都不能证明模型身份或全部能力。

Token 少的模型一定更便宜吗？

不一定。总费用同时取决于 Token 数、输入输出单价、缓存、重试及其他计费项目。先计算实际任务用量，再比较当前价格。

价格、模型和样例多久更新？

各工具显示自己的快照或样例日期，当前指南核对日期为 2026-09-30。它们不是实时报价或质量排名，选型前请查看来源与最新文档。
