このツールで防げるよくあるミス
/v1 の不足
OpenAI-compatible SDKs usually need the Base URL to include /v1. Use https://crazyrouter.com/v1, not just the domain.
API Key の間違い
If you use the Crazyrouter Base URL, use a Crazyrouter API key from your dashboard, not a provider-native key.
リージョン不一致
If global access is unstable, switch only the Base URL to https://cn.crazyrouter.com/v1. Keep the same API key and model name.
