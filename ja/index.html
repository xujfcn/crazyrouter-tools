client = OpenAI(
    api_key="YOUR_CRAZYROUTER_KEY",
    base_url="https://crazyrouter.com/v1"
)

    model="gpt-5-mini",
    messages=[
        {"role": "user", "content": "Hello from Crazyrouter"}
    ]
)

print(resp.choices[0].message.content)

よくある質問

このページにはどの AI ツールがありますか？
現在公開中のツールは、AI API 料金計算機、AI モデル比較、AI モデルレーダー、AI モデル公開タイムラインです。料金評価、調査、トレンド追跡、モデル選定をまとめて支援します。
これらのツールは無料ですか？
はい。公開ツールは無料で利用できます。開発前に AI API 料金、モデル比較、Token-based costs を理解するために設計されています。
ツール利用に Crazyrouter アカウントは必要ですか？
いいえ。ログインなしで閲覧・利用できます。実際に複数モデルへ API call する場合は Crazyrouter API Key が必要です。
プロバイダーの料金ページを見るだけと何が違いますか？
公式料金ページは通常 raw rates を示すだけで、実ワークロードでプロバイダーを横比較できません。これらのツールは Token 料金と model data を実用的な購入・アーキテクチャ判断に変えるためのものです。
見積もりではなく実際の料金はどこで見られますか？
最新のモデルと料金は crazyrouter.com/models を確認してください。計算機は計画に便利ですが、live pricing が正しい情報源です。
