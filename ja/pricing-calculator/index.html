よくある質問

Crazyrouter はなぜ低価格を提供できるのですか？
Crazyrouter は多数の開発者需要を集約し、プロバイダーとボリューム価格を交渉します。その節約分をユーザー価格に反映しており、通常は公式価格より約 45% 低くなります。
この計算機の価格は正確ですか？
この計算機は各プロバイダーの公開価格を参考にし、Crazyrouter 価格をその 55% として見積もります。実際の費用は変動する場合があるため、リアルタイム価格は crazyrouter.com/models を確認してください。
Token とは何ですか？
Token は AI モデルがテキストを処理する基本単位です。英語ではおよそ 1 token が 4 文字、または 0.75 語程度に相当します。1,000 語の記事はおよそ 1,300 token です。
コードを変更せずにモデルを切り替えられますか？
はい。Crazyrouter は OpenAI 互換 API を使用しています。リクエスト内のモデル名を変更するだけで、SDK の変更や新しい API Key は不要です。Python、Node.js、curl、LangChain などで利用できます。
画像生成や動画生成に対応していますか？
はい。Crazyrouter は DALL-E 3、Midjourney、Flux、Stable Diffusion、Sora、Kling、Runway などに対応し、統一 API から利用できます。
Crazyrouter は OpenRouter と何が違いますか？
Crazyrouter はより多くのモデル（627+ 対 約 300）、より低い価格、さらに画像・動画・音声生成モデルへの対応を提供します。API 形式は OpenAI 互換です。
