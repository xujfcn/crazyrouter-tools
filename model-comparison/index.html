What this comparison includes

This is a pricing shortlist, not a model quality ranking. The published snapshot was collected on 2026-10-11 and does not establish current availability.

  • Prices are in USD per million input or output tokens for CrazyRouter’s default group. Account discounts, cache, long-context tiers, tools, image charges, and taxes may differ or require separate treatment.
  • Context windows, MMLU, HumanEval, MATH, vision, and tool-calling capabilities are not included because this dataset has no verified per-model evidence. A missing value does not mean a capability is unsupported. Provider documentation links are references for checking, not evidence of a completed review.
