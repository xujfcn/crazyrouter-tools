How to compare candidates

  1. Use the exact same prompts and record the model ID, API protocol and generation settings.
  2. For coding, check executable results and tool-call arguments. A model name alone does not establish protocol support.
  3. For documents, check retrieval accuracy and citations at the actual input size.
  4. Record total billed cost, latency and failed requests. Compare several runs; one example is not a benchmark.
