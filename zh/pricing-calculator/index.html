常见问题

Crazyrouter 为什么能提供更低价格？
Crazyrouter 汇聚大量开发者需求，并与供应商协商批量价格。节省下来的成本会直接体现在用户价格中，通常约为官方价格的 45% 折扣。
这个计算器里的价格准确吗？
计算器会参考各供应商的公开标价，并按 55% 估算 Crazyrouter 价格。实际费用可能会变化，请以 crazyrouter.com/models 的实时价格为准。
Token 是什么？
Token 是 AI 模型处理文本的基本单位。英文中大约 1 个 token 等于 4 个字符，约为 0.75 个单词。一篇 1,000 词的英文文章通常约为 1,300 个 token。
不改代码可以切换模型吗？
可以。Crazyrouter 使用 OpenAI 兼容 API。你只需要修改请求里的模型名称，不需要更换 SDK，也不需要新的 API Key。Python、Node.js、curl、LangChain 等都可以使用。
支持图像和视频生成吗？
支持。Crazyrouter 支持 DALL-E 3、Midjourney、Flux、Stable Diffusion、Sora、Kling、Runway 等模型，并通过统一 API 调用。
Crazyrouter 和 OpenRouter 有什么不同？
Crazyrouter 提供更多模型（627+ 对比约 300）、更低价格，并支持更多图像、视频、音频生成模型，同时保持 OpenAI 兼容 API 格式。
